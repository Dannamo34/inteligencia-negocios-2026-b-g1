## ETL steps & measures

The dataset used in this activity is a CSV file containing a directory of health secretariats in Colombia. First, the data types were reviewed and the numeric columns were converted to integer values while the descriptive columns were kept as text. The `nomentidad` column was cleaned by trimming unnecessary spaces and removing non-printable characters. The `nomubicacion` column was standardized using uppercase text formatting. A missing value in `nomemail_2` was replaced with the text `Sin segundo correo`. A conditional column called `TipoDepartamento` was created using the `depto` field. Three DAX measures were created: `Total Secretarias` uses SUM, `Promedio Registros` uses AVERAGE, and `Porcentaje Con Departamento` uses DIVIDE. A slicer based on `nomubicacion` was also added to demonstrate filter context because the `Total Secretarias` measure changes when a specific location is selected.
